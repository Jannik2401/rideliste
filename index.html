Anmelden

Zum Eintragen brauchst du einen GitHub-Zugang mit Schreibrechten auf dieses Repository. Lesen kann jeder ohne Anmeldung.

  1. Auf GitHub: Settings → Developer settings → Personal access tokens → Tokens (classic) → neues Token
  2. Haken bei public_repo setzen, Ablaufdatum wählen
  3. Token hier einfügen

Das Token wird nur in diesem Browser gespeichert. Auf fremden Geräten danach „Abmelden“ klicken.
